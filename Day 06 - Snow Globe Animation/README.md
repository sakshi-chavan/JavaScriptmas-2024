<h2>Challenge</h2>
<p>
  <ol>
    <li>Write JavaScript to create a snowflake and make it fall inside the snow globe. The snowflake should have a random starting position, animation duration, and size.</li>
    <li>See index.css</li>
  </ol>
  Stretch Goals:
  <ol>
    <li>Give some variety to your snowflakes, so they are not all the same. Perhaps every 25th one could be a snowman ☃️?</li>
    <li>Remove each snowflake after a set time - this will stop the scene from being lost in a blizzard!</li>
    <li>Add a button that makes the snow start falling, it could trigger a CSS-animated shake of the snow globe. Then make the snow become less frequent until it slowly stops - until the button is pressed again.</li>
    <li>Change the direction of the snowflakes so they don’t all fall vertically.</li>
    <li>Make the style your own! </li>
  </ol>
</p>
