<h2>Challenge</h2>
<p>
  <ul>
    <li>Generate an elf first and last name that matches the user’s first and last name initials, then display it on the screen.</li>
    <li>Example: if the user’s name is "John Doe," the elf name could be "Joyful Dazzle."</li>
    <li>Display the generated elf names in the "Registered Employees" list.</li>
  </ul>
</p>

<p>
  Stretch Goals:
  <ul>
    <li>Generate the elf names using an LLM API (like HuggingFace).</li>
    <li>Don't save the same name twice. (not necessary for the normal task)</li>
    <li>Make sure to use Scrimba's environment variables feature so you don't expose your API key</li>
  </ul>

</p>
