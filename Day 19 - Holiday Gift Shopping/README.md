<h2>Challenge</h2>
<p>
  You're shopping for holiday gifts, but money is tight so we need to consider the cheapest items first.
<ul>
  <li>
    Use JavaScript's built-in array sort() (or toSorted()) method to write a function that returns an array of products sorted by price, cheapest to most expensive.  
  </li>
  <li> Log the sorted array to the console to double-check you solved it correctly.</li>
</ul>
</p>

          🧁: $2.99
