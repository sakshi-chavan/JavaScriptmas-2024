<h2>Challenge</h2>
<p>The cool people of Lapland are bored of traditional social media and have decided to build their own app called Northagram...and they need your help!</p>
<p>
  This is how the app should work:
  <ul>
    <li>It displays circular avatars of the friends who have uploaded pictures lately. These avatars have a white border.</li>
    <li>Underneath, it cycles through the friends' pictures displaying each for 1.5 seconds. (There's an animated snowman loading state before pictures load.)</li>
    <li>While a friend's pictures are being displayed, that friend's avatar gets a red border.</li>
    <li>This red border reverts to white when their pictures have finished being displayed.</li>
    <li> When all of the images have been displayed, the user should see a message "Refresh to load latest images". All avatars should have a white border at this point.</li>
  </ul>
</p>
<br>
<p>Stretch Goals for dedicated Social Media Engineers:</p>
<ul>
  <li>Add captions to the images.</li>
  <li>Refactor your code to use generators!</li>
  <li>Grey out the avatar after that friend's pictures have been displayed.</li>

  <li>Make it so clicking on an image pauses the timer.</li>

  <li>Add left and right arrow overlays to the image so users can scroll back and forth.</li>
</ul>
