<h2>Challenge</h2>
<ul>
   <li>This is a classic "Find the Pair" game with a christmas theme.
   <li>The player should be able to reveal cards by clicking on them.
   <li>When the player reveals one card, it should stay revealed until a second card is revealed.
   <li>When the player reveals two cards:
       <ul>
         <li>If they are the same, they should remain revealed for the rest of the game.</li>
         <li>If they are different, they should be flipped back to hidden.</li>
       </ul>
   <li>The cards should be shuffled at the start of each game.
</ul>


<p>***Stretch Goals***</p>
<ul>
  <li>Add a point system where points are awarded for each correctly revealed pair and deducted for each incorrect pair (you decide the exact points for each action).</li>
  <li>Implement a high-score system using the browser's local storage.</li>
  <li>Add a "Restart Game" button that appears when the game ends so the user can start over.</li>
</ul>
