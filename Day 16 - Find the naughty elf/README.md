<h2>Challenge</h2>

<p>Santa has grown suspicious that one of his elves isn't playing fair. The elves are paid well to make toys but Santa thinks one of the elves is keeping some of the toys he has made (and probably selling them on the black market in one of Laplands dodgier neighbourhoods.)</p>
<p>
Santa has written a script to recursively look over the data and find discrepancies. But Santa is not so great at coding and he has got bugs he can't resolve.
</p>
<p>This code should:
<ul>
  <li>Traverse through all elves.</li>
  <li>Traverse toysShipped, summing up toy counts across regions and subregions.</li>
  <li>Compare the aggregated counts with toysMade to determine discrepancies.</li>
</ul>
But it doesn't!</p>

<p>Your task: debug this code - there are two bugs to find! </p>
<p>Stretch Goal</p>
<ul>

  <li>Recursion is hard! Delete everything in index.js and start again from scratch. You don't have to do it the same way. Perhaps you can find a better way.</li>
</ul>
